# Kanban Board

A modern Kanban Task Management App built with React, Context API, and Tailwind CSS.

## Features

- Create, Edit, and Delete Tasks
- Drag & Drop Between Columns
- Task Priorities (Low, Medium, High)
- Deadline Dates & Overdue Indicators
- Responsive UI
- Context API State Management

## Tech Stack

- React JS
- Context API
- Tailwind CSS
- React Icons
- Vite

## Run Locally

```bash
npm install
npm run dev
```

## Columns

- To Do
- In Progress
- Done
